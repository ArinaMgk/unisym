# Naming

**macro** ABC
**namespace** a_b
**class** AaaBbb
- **field** a_b
- **method** (aaa)Bbb, aaa can be: `en`, `get`, `set`

## C/C++

- Avoid using stddef.h, stdint.h and inttypes.h
- Normally inc/ stores header files, while lib/ stores source files
