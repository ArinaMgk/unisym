# DASM 反汇编器

DASM 将机器码输入解析为汇编文本。架构相关的解码由 Archend 解码接口提供；DASM
负责命令选项、输入读取、地址推进、同步点和文本输出。

## 当前支持

- 反汇编架构：x86。
- x86 位宽：16、32、64 位，具体位宽还会受所选 CPU 等级约束。
- 输入格式：`bin` 平坦二进制字节流。
- x86 厂商偏好：`intel`、`amd`、`cyrix`、`idt`、`centaur`、`winchip`。

当前尚未支持 ELF、COFF 等带 section、symbol 和 relocation 信息的输入格式。

## 命令选项

```text
dasm [-f format] [-march=name] [-b bits] [options...] [--] file
```

- `-h`：显示完整帮助，以及当前支持的架构、BITS、CPU/INST 和输入格式。
- `-ha`：只显示可用于反汇编的架构及其 BITS、CPU/INST 信息。
- `-hf`：只显示输入格式及其可用架构。
- `-march=name`、`--arch name`：选择反汇编架构。
- `-b bits`：选择处理器位宽；x86 当前支持 16、32、64。
- `-u`、`-uu`：分别等价于选择 32 位和 64 位。
- `-f format`：选择输入格式，当前只支持 `bin`。
- `-o origin`：设置平坦二进制输入的起始地址。
- `-e bytes`：跳过输入开头的指定字节数。
- `-k start,bytes`：将指定输入范围作为数据跳过，不进行反汇编。
- `-s offset`：增加一个指令同步点。
- `-a`、`-i`：启用自动指令同步。
- `-p vendor`：设置 x86 厂商指令偏好。
- `-v`、`-r`：显示版本信息。
- `--`：结束命令选项解析，后续参数作为文件名处理。

输入文件名为 `-` 时，DASM 从标准输入读取数据。

## 架构与输入格式

Archend 为汇编和反汇编共同提供架构元信息，并为 DASM 提供单条指令解码接口。当前
x86 解码器位于 `lib/cpp/Lango/Archend/x86/Decoder-x86.cpp`。

Codeend 是 AASM 的代码输出格式接口，不是 DASM 的输入格式接口。因此 DASM 的
`-h` 会明确显示 Codeend 不适用，并另外列出 `-f` 可选择的输入格式。后续支持 ELF
等对象文件时，应增加对应的输入格式读取层，而不是直接复用 Codeend 输出接口。

## 地址与同步

对于 `bin` 输入，DASM 从 `-o` 指定的地址开始逐条推进。手动同步点由 `-s` 和 `-k`
建立；启用自动同步后，Archend 可以在解码结果中返回直接控制流目标，DASM 再将该
目标加入同步信息。架构解码器本身不直接修改 DASM 的同步表。

## 当前限制

- 仅注册 x86 反汇编器，其他 Archend 目前只提供汇编能力。
- 仅接受平坦二进制输入，不读取对象文件中的 section、symbol 或 relocation。
- 输出为文本清单，尚未提供结构化反汇编结果或可重定位输出。
